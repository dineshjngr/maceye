## [0.1.0] - 2026-11-25

First public release. This is an early version: it works, but it has only been tested on one Mac.

### Added

- Eyes in the menu bar that follow the pointer.
- Floating desktop eyes that can be dragged anywhere, with one pair per display as an option.
- Six themes (Classic, Cartoon, Cat, Robot, Sleepy, Angry) and custom colours.
- Moods with eyelids and eyebrows, including an automatic mood.
- One to eight eyes with adjustable size and spacing.
- Natural blinking, sleep when the Mac is idle, and click an eye to blink.
- Reactions to a fast pointer, a shaken pointer and typing.
- Optional googly physics.
- Optional look-at-the-text-cursor mode.
- CPU and battery signals, an eye-break reminder, and a microphone and camera signal.
- Find My Pointer.
- System-wide keyboard shortcuts.
- `maceye://` links for the Shortcuts app and scripts.
- Shortcuts app actions (shown by macOS only in developer-signed builds).
- Desktop widgets, one per theme.
- Optional settings sync through iCloud Drive.
- Open at login.

### Known issues

- Release builds are ad-hoc signed and not notarized. See the README for how to open them.
- Widgets from ad-hoc signed builds may not appear in the widget gallery on every macOS version.
